## 학습 경로

- Python 기본 문법을 먼저 훑고, 함수와 객체로 로직을 묶은 뒤 Streamlit으로 작은 화면을 만들어 본다.
- 처음 읽을 때는 정의 노트보다 흐름 노트를 먼저 보고, 막히는 용어만 Permanent Note로 내려간다.

- 해결 후에는 관련 Permanent Note의 확인 질문에 실제 사례를 한 줄로 남긴다.
