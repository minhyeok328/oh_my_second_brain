# 앙상블 학습

태그: #machinelearning #ensemble #llm_wiki

## 한 줄 정의

여러 모델을 결합해 단일 모델보다 안정적이거나 강한 예측을 만드는 방법이다.

## 왜 중요한가

다른 오류 패턴을 가진 모델을 결합하면 일반화 성능이 개선될 수 있다.

## 핵심 개념

- 배깅은 분산을 줄인다.
- 부스팅은 약한 모델을 순차적으로 보완한다.
- 스태킹은 여러 모델 출력을 다시 학습한다.

## 예제

```python
# RandomForest, XGBoost, CatBoost는 대표적인 앙상블 계열 모델
```

## 실무 활용

대회형 탭ular 문제, 운영 예측 모델, 추천 랭킹 후보 점수화에 자주 쓰인다.

## 내 말로 다시 설명

앙상블 학습은/는 강의에서 나온 개념을 정의, 사용 조건, 주의점, 연결 개념으로 다시 설명하기 위한 LLM wiki 원자 노트다. 단순 암기보다 실제 문제에서 언제 꺼내 쓸지 판단하는 데 초점을 둔다.

## 언제 쓰는가

- 강의 실습 코드에서 같은 개념을 다시 만날 때
- 프로젝트에서 관련 오류나 설계 결정을 설명해야 할 때
- [[Random Forest]], [[XGBoost]], [[CatBoost]]와 함께 문제 원인을 좁힐 때

## 언제 쓰면 안 되는가

- 구체적인 API 버전, 파라미터, 보안 정책이 필요한 경우에는 공식 문서를 먼저 확인한다.
- 예제 하나만 보고 모든 상황에 일반화해야 할 때는 보류한다.
- 이미 더 좁고 구체적인 노트가 있는 경우에는 그 노트로 이동한다.

## 자주 헷갈리는 점

- 이름이 비슷한 인접 개념과 책임 범위가 다를 수 있다.
- 강의 예제의 상황과 실제 프로젝트의 데이터, 환경, 버전 차이를 분리해야 한다.
- "동작한다"와 "운영에서 유지보수 가능하다"는 다른 기준이다.
