# 정적 웹 스크래핑

태그: #webscraping #data_collection #llm_wiki

## 한 줄 정의

서버가 내려준 HTML을 파싱해 필요한 텍스트와 링크를 추출하는 수집 방식이다.

## 왜 중요한가

API가 없을 때 웹 공개 정보를 구조화할 수 있다. 페이지 구조 변경과 이용약관을 고려해야 한다.

## 핵심 개념

- HTML 문서를 요청한다.
- CSS selector나 XPath로 요소를 찾는다.
- 인코딩과 robots 정책을 확인한다.

## 예제

```python
html = requests.get(url).text
# BeautifulSoup 또는 lxml로 title, href 등을 추출
```

## 실무 활용

뉴스 제목 수집, 상품 목록 크롤링, 학습용 문서 후보 수집에 쓰인다.

## 내 말로 다시 설명

정적 웹 스크래핑은/는 강의에서 나온 개념을 정의, 사용 조건, 주의점, 연결 개념으로 다시 설명하기 위한 LLM wiki 원자 노트다. 단순 암기보다 실제 문제에서 언제 꺼내 쓸지 판단하는 데 초점을 둔다.

## 언제 쓰는가

- 강의 실습 코드에서 같은 개념을 다시 만날 때
- 프로젝트에서 관련 오류나 설계 결정을 설명해야 할 때
- [[Requests]], [[HTML]], [[NLP 전처리]]와 함께 문제 원인을 좁힐 때

## 언제 쓰면 안 되는가

- 구체적인 API 버전, 파라미터, 보안 정책이 필요한 경우에는 공식 문서를 먼저 확인한다.
- 예제 하나만 보고 모든 상황에 일반화해야 할 때는 보류한다.
- 이미 더 좁고 구체적인 노트가 있는 경우에는 그 노트로 이동한다.

## 자주 헷갈리는 점

- 이름이 비슷한 인접 개념과 책임 범위가 다를 수 있다.
- 강의 예제의 상황과 실제 프로젝트의 데이터, 환경, 버전 차이를 분리해야 한다.
- "동작한다"와 "운영에서 유지보수 가능하다"는 다른 기준이다.
