# 신경망 출력층

태그: #deeplearning #neuralnetwork #llm_wiki

## 한 줄 정의

문제 유형에 맞게 모델의 최종 출력을 구성하는 층이다.

## 왜 중요한가

출력층과 손실 함수가 맞지 않으면 학습 목표가 틀어진다. 분류, 회귀, 다중라벨 문제마다 설계가 다르다.

## 핵심 개념

- 회귀는 보통 선형 출력이다.
- 이진 분류는 sigmoid 또는 logits 기반 손실을 쓴다.
- 다중 클래스는 softmax 계열 해석을 사용한다.

## 예제

```python
head = nn.Linear(hidden_dim, num_classes)
```

## 실무 활용

이미지 분류, 텍스트 분류, 회귀 모델의 마지막 계층 설계에 쓰인다.

## 언제 쓰는가

- 강의 실습 코드에서 같은 개념을 다시 만날 때
- 프로젝트에서 관련 오류나 설계 결정을 설명해야 할 때
- [[손실함수]], [[분류 평가 지표]], [[Text Classification]]와 함께 문제 원인을 좁힐 때

## 언제 쓰면 안 되는가

- 구체적인 API 버전, 파라미터, 보안 정책이 필요한 경우에는 공식 문서를 먼저 확인한다.
- 예제 하나만 보고 모든 상황에 일반화해야 할 때는 보류한다.
- 이미 더 좁고 구체적인 노트가 있는 경우에는 그 노트로 이동한다.

## 자주 헷갈리는 점

- 이름이 비슷한 인접 개념과 책임 범위가 다를 수 있다.
- 강의 예제의 상황과 실제 프로젝트의 데이터, 환경, 버전 차이를 분리해야 한다.
