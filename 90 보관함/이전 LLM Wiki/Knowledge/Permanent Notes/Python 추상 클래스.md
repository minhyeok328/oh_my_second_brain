# Python 추상 클래스

태그: #python #oop #llm_wiki

## 한 줄 정의

공통 인터페이스만 정의하고 구체 구현은 하위 클래스에 맡기는 클래스다.

## 왜 중요한가

여러 구현체가 같은 사용법을 가져야 할 때 계약을 세운다. 플러그인, 모델, 도구 추상화에 적합하다.

## 핵심 개념

- `abc.ABC`와 `@abstractmethod`를 사용한다.
- 추상 메서드를 구현하지 않으면 인스턴스화할 수 없다.
- 다형성을 통해 호출자는 구체 타입을 몰라도 된다.

## 예제

```python
from abc import ABC, abstractmethod
class Retriever(ABC):
    @abstractmethod
    def search(self, query): ...
```

## 실무 활용

RAG retriever 교체, 모델 인터페이스 통일, 서비스 계층 테스트 더블 구성에 활용한다.
