# Python 조건문

태그: #python #programming #llm_wiki

## 한 줄 정의

조건의 참거짓에 따라 실행 경로를 나누는 제어문이다.

## 왜 중요한가

데이터 검증, 예외 상황 처리, 사용자 입력 분기처럼 프로그램이 현실의 불확실성을 다루게 해준다.

## 핵심 개념

- `if`, `elif`, `else`로 분기를 만든다.
- 비어 있는 컬렉션과 `None`은 조건에서 거짓처럼 평가된다.
- 조건은 작고 읽기 쉽게 분리하는 편이 좋다.

## 예제

```python
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
else:
    grade = "C"
```

## 실무 활용

전처리 규칙, API 실패 처리, 추천 조건 분기에 사용한다.

## 언제 쓰면 안 되는가

- 구체적인 API 버전, 파라미터, 보안 정책이 필요한 경우에는 공식 문서를 먼저 확인한다.
- 예제 하나만 보고 모든 상황에 일반화해야 할 때는 보류한다.
- 이미 더 좁고 구체적인 노트가 있는 경우에는 그 노트로 이동한다.
