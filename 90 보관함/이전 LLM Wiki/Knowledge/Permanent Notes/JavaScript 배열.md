# JavaScript 배열

태그: #javascript #web #llm_wiki

## 한 줄 정의

순서 있는 값을 저장하고 변환 메서드를 제공하는 JavaScript 컬렉션이다.

## 왜 중요한가

목록 UI, API 응답, DOM 요소 목록 처리에서 가장 많이 만나는 구조다.

## 핵심 개념

- `map`, `filter`, `reduce`는 함수형 변환을 제공한다.
- 원본 변경 메서드와 새 배열 반환 메서드를 구분한다.
- 배열은 객체이므로 참조 공유에 주의한다.

## 예제

```js
const names = users.filter(u => u.active).map(u => u.name);
```

## 실무 활용

테이블 렌더링, 검색 결과 필터링, 비동기 응답 목록 처리에 사용한다.
