# useRef

태그: #react #hook #llm_wiki

## 한 줄 정의

렌더링을 유발하지 않는 mutable 값 또는 DOM 참조를 보관하는 Hook이다.

## 왜 중요한가

값은 기억해야 하지만 화면을 다시 그릴 필요가 없는 경우 state보다 적합하다.

## 핵심 개념

- `.current`에 값을 저장한다.
- 값 변경이 렌더링을 일으키지 않는다.
- DOM 요소에 직접 접근할 때 ref를 연결한다.

## 예제

```jsx
const inputRef = useRef(null);
inputRef.current?.focus();
```

## 실무 활용

입력 포커스, 이전 값 저장, 타이머 id 보관, 외부 라이브러리 DOM 연결에 사용한다.
