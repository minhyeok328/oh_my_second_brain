# CLIP

태그: #multimodal #vision #nlp #llm_wiki

## 한 줄 정의

이미지와 텍스트를 같은 임베딩 공간에 정렬하도록 학습한 멀티모달 모델이다.

## 왜 중요한가

텍스트로 이미지를 검색하거나, 이미지와 설명의 의미적 유사도를 계산하는 기반이 된다.

## 핵심 개념

- 이미지 인코더와 텍스트 인코더가 있다.
- 대조학습으로 매칭 쌍은 가깝게, 비매칭 쌍은 멀게 만든다.
- Zero-shot 이미지 분류가 가능하다.

```python
# similarity = image_embedding @ text_embedding.T
```

## 실무 활용

이미지 검색, 멀티모달 RAG, 라벨 없는 이미지 분류 후보 생성에 사용한다.

## 내 말로 다시 설명

CLIP은/는 강의에서 나온 개념을 정의, 사용 조건, 주의점, 연결 개념으로 다시 설명하기 위한 LLM wiki 원자 노트다. 단순 암기보다 실제 문제에서 언제 꺼내 쓸지 판단하는 데 초점을 둔다.

## 언제 쓰는가

- 강의 실습 코드에서 같은 개념을 다시 만날 때
- 프로젝트에서 관련 오류나 설계 결정을 설명해야 할 때
- [[BLIP]], [[Multimodal RAG]], [[Embedding]]와 함께 문제 원인을 좁힐 때

## 언제 쓰면 안 되는가

- 구체적인 API 버전, 파라미터, 보안 정책이 필요한 경우에는 공식 문서를 먼저 확인한다.
- 예제 하나만 보고 모든 상황에 일반화해야 할 때는 보류한다.
- 이미 더 좁고 구체적인 노트가 있는 경우에는 그 노트로 이동한다.

## 자주 헷갈리는 점

- 이름이 비슷한 인접 개념과 책임 범위가 다를 수 있다.
- 강의 예제의 상황과 실제 프로젝트의 데이터, 환경, 버전 차이를 분리해야 한다.
- "동작한다"와 "운영에서 유지보수 가능하다"는 다른 기준이다.
