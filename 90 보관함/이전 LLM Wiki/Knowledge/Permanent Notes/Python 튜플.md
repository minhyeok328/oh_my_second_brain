# Python 튜플

태그: #python #programming #llm_wiki

## 한 줄 정의

순서가 있지만 변경할 수 없는 값의 묶음이다.

## 왜 중요한가

함수 반환값, 좌표, 불변 설정처럼 의미상 바뀌면 안 되는 작은 묶음을 안전하게 표현한다.

## 핵심 개념

- 불변이므로 원소를 직접 바꿀 수 없다.
- 패킹과 언패킹으로 여러 값을 간결하게 다룬다.
- 딕셔너리 키로 사용할 수 있다.

## 예제

```python
point = (3, 5)
x, y = point
```

## 실무 활용

모델 평가 결과 `(score, params)`나 데이터 좌표를 반환할 때 명확한 구조를 제공한다.

## 언제 쓰면 안 되는가

- 예제 하나만 보고 모든 상황에 일반화해야 할 때는 보류한다.
- 이미 더 좁고 구체적인 노트가 있는 경우에는 그 노트로 이동한다.
