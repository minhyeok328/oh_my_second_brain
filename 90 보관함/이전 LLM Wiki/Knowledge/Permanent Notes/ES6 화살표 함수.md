# ES6 화살표 함수

태그: #javascript #web #llm_wiki

## 한 줄 정의

짧은 함수 표현과 lexical `this`를 제공하는 JavaScript 함수 문법이다.

## 왜 중요한가

배열 변환과 콜백을 간결하게 만들고, `this` 바인딩 혼란을 줄인다.

## 핵심 개념

- `(x) => x * 2` 형태로 쓴다.
- 자신만의 `this`를 만들지 않는다.
- 복잡한 로직은 블록 본문과 명시적 return을 쓴다.

## 예제

```js
const doubled = nums.map(n => n * 2);
```

## 실무 활용

이벤트 핸들러, Promise 콜백, 배열 map/filter에 자주 사용한다.
