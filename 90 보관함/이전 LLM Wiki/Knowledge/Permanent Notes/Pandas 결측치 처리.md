# Pandas 결측치 처리

태그: #pandas #data_analysis #llm_wiki

## 한 줄 정의

비어 있거나 알 수 없는 값을 탐지하고 제거하거나 대체하는 과정이다.

## 왜 중요한가

결측치를 방치하면 통계량, 모델 학습, 시각화가 왜곡된다. 결측의 원인을 이해한 뒤 처리해야 한다.

## 핵심 개념

- `isna`, `notna`로 탐지한다.
- `dropna`는 제거, `fillna`는 대체다.
- 평균 대체가 항상 정답은 아니며 도메인 해석이 필요하다.

## 예제

```python
df["age"] = df["age"].fillna(df["age"].median())
```

## 실무 활용

타이타닉 EDA, 고객 데이터 정제, 모델 입력 전처리에서 필수 단계다.
