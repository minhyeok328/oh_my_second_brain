# Pandas 인덱싱

태그: #pandas #data_analysis #llm_wiki

## 한 줄 정의

DataFrame과 Series에서 원하는 행과 열을 선택하는 방법이다.

## 왜 중요한가

정확한 선택은 분석의 신뢰도를 좌우한다. 위치와 라벨, 조건 필터의 차이를 알아야 한다.

## 핵심 개념

- `loc`은 라벨 기반이다.
- `iloc`은 위치 기반이다.
- 불리언 마스크로 조건 필터링한다.

## 예제

```python
adults = df.loc[df["age"] >= 20, ["name", "age"]]
```

## 실무 활용

이상치 필터링, 학습/평가 컬럼 분리, 특정 조건의 사용자 집단 분석에 쓰인다.
