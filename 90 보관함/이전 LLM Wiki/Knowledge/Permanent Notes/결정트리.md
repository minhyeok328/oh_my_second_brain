# 결정트리

태그: #machinelearning #classification #llm_wiki

## 한 줄 정의

피처 조건으로 데이터를 반복 분할해 예측 규칙을 만드는 모델이다.

## 왜 중요한가

해석하기 쉽고 비선형 관계를 잡지만 깊어지면 과적합하기 쉽다.

## 핵심 개념

- 노드는 분기 조건, 리프는 예측값을 가진다.
- 불순도 감소 기준으로 분할한다.
- 깊이와 최소 샘플 수가 복잡도를 제어한다.

## 예제

```python
model = DecisionTreeClassifier(max_depth=4, random_state=42)
```

## 실무 활용

규칙 기반 설명이 필요한 분류, 앙상블 모델의 기본 구성요소로 활용한다.

## 내 말로 다시 설명

결정트리은/는 강의에서 나온 개념을 정의, 사용 조건, 주의점, 연결 개념으로 다시 설명하기 위한 LLM wiki 원자 노트다. 단순 암기보다 실제 문제에서 언제 꺼내 쓸지 판단하는 데 초점을 둔다.

## 언제 쓰는가

- 강의 실습 코드에서 같은 개념을 다시 만날 때
- 프로젝트에서 관련 오류나 설계 결정을 설명해야 할 때
- [[Random Forest]], [[XGBoost]], [[과적합]]와 함께 문제 원인을 좁힐 때

## 언제 쓰면 안 되는가

- 구체적인 API 버전, 파라미터, 보안 정책이 필요한 경우에는 공식 문서를 먼저 확인한다.
- 예제 하나만 보고 모든 상황에 일반화해야 할 때는 보류한다.
- 이미 더 좁고 구체적인 노트가 있는 경우에는 그 노트로 이동한다.

## 자주 헷갈리는 점

- 이름이 비슷한 인접 개념과 책임 범위가 다를 수 있다.
- 강의 예제의 상황과 실제 프로젝트의 데이터, 환경, 버전 차이를 분리해야 한다.
- "동작한다"와 "운영에서 유지보수 가능하다"는 다른 기준이다.
