# 활성화 함수

태그: #deeplearning #neuralnetwork #llm_wiki

## 한 줄 정의

신경망에 비선형성을 부여하는 함수다.

## 왜 중요한가

활성화 함수가 없으면 여러 층을 쌓아도 하나의 선형 변환과 같다. 비선형 패턴 학습의 핵심이다.

## 핵심 개념

- ReLU는 음수를 0으로 만들고 양수는 유지한다.
- Sigmoid는 0~1 확률 표현에 적합하다.
- Softmax는 다중 클래스 확률 분포를 만든다.

## 예제

```python
import torch.nn as nn
layer = nn.ReLU()
```

## 실무 활용

은닉층, 출력층 설계, 분류 문제 확률 해석에 사용한다.
