# Python 반복문

태그: #python #programming #llm_wiki

## 한 줄 정의

컬렉션이나 조건을 기준으로 같은 작업을 반복 실행하는 제어문이다.

## 왜 중요한가

파일 목록 처리, 데이터 행 순회, API 페이지네이션, 학습 epoch처럼 반복은 자동화의 핵심이다.

## 핵심 개념

- `for`는 iterable을 순회한다.
- `while`은 조건이 참인 동안 반복한다.
- `break`와 `continue`로 흐름을 제어한다.

## 예제

```python
for path in files:
    print(path.name)
```

## 실무 활용

데이터 수집 루프, 모델 학습 루프, 일괄 파일 변환에 사용한다.

## 언제 쓰면 안 되는가

- 구체적인 API 버전, 파라미터, 보안 정책이 필요한 경우에는 공식 문서를 먼저 확인한다.
- 예제 하나만 보고 모든 상황에 일반화해야 할 때는 보류한다.
- 이미 더 좁고 구체적인 노트가 있는 경우에는 그 노트로 이동한다.

## 자주 헷갈리는 점

- 이름이 비슷한 인접 개념과 책임 범위가 다를 수 있다.
- 강의 예제의 상황과 실제 프로젝트의 데이터, 환경, 버전 차이를 분리해야 한다.
