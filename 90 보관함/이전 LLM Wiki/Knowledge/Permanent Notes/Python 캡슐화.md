# Python 캡슐화

태그: #python #oop #llm_wiki

## 한 줄 정의

객체 내부 상태를 직접 노출하지 않고 메서드를 통해 다루게 하는 설계 원칙이다.

## 왜 중요한가

상태 변경 규칙을 한 곳에 모으면 잘못된 값이 퍼지는 것을 막고 클래스 사용법을 명확히 할 수 있다.

## 핵심 개념

- Python은 강한 private 대신 관례적 `_name`을 사용한다.
- property로 읽기/쓰기 규칙을 정의한다.
- getter/setter는 검증 로직이 있을 때 의미가 있다.

## 예제

```python
class Account:
    def __init__(self):
        self._balance = 0
```

## 실무 활용

사용자 포인트, 모델 설정, 세션 상태처럼 값의 무결성이 중요한 객체에 적용한다.

- 예제 하나만 보고 모든 상황에 일반화해야 할 때는 보류한다.
- 이미 더 좁고 구체적인 노트가 있는 경우에는 그 노트로 이동한다.
