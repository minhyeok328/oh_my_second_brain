# Python 형변환

태그: #python #programming #llm_wiki

## 한 줄 정의

값을 다른 자료형으로 명시적으로 바꾸는 과정이다.

## 왜 중요한가

입력값은 문자열로 들어오는 경우가 많다. 적절한 변환 없이는 계산, 비교, 저장이 의도와 다르게 동작한다.

## 핵심 개념

- `int`, `float`, `str`, `bool`, `list` 등 생성자를 사용한다.
- 실패 가능한 변환은 예외 처리가 필요하다.
- CSV와 웹 입력은 스키마에 맞게 변환해야 한다.

## 예제

```python
age = int("20")
ratio = float("0.85")
```

## 실무 활용

폼 입력 처리, CSV 로딩, 모델 피처 변환에서 데이터 타입을 명시적으로 정리한다.
