# 외부 참조 정책

태그: #llm_wiki #source

## 기본 입장

이 vault는 공식 지식 중심 LLM Wiki로 운영한다. API 동작, 옵션, 버전, 권장 패턴은 공식 문서를 1차 근거로 삼고, `C:\lecture` 강의 자료는 학습 흐름과 실습 맥락의 1차 원천으로 사용한다.

## 우선순위

- 공식 문서: API, 옵션, 버전, 권장 패턴, 표준 동작 확인
- 강의 자료: 실제 학습 흐름, 실습 코드, 수업에서 강조한 판단 기준 확인
- 검증된 레퍼런스와 논문: 알고리즘, 모델, 용어의 표준 설명 확인
- Wikipedia와 일반 wiki: 큰 개념의 역사, 범위, 용어를 빠르게 확인할 때만 보조로 사용
- 프로젝트 노트: 공식 지식의 근거가 아니라 실제 적용 사례로만 사용

## 기록 방식

- 외부 자료를 사용한 노트는 frontmatter의 `external`과 본문 `외부 참조`에 URL을 남긴다.
- 강의와 외부 문서가 다르면 어느 쪽이 어떤 맥락에서 맞는지 적는다.
- 프로젝트 경험과 공식 문서가 다르면 프로젝트 환경, 버전, 개인 확장 여부를 분리해서 적는다.
- LLM 답변에 넣을 근거는 가능하면 원문 경로, 공식 문서 URL, 노트 링크를 함께 준다.
