# Knowledge Vault

태그: #llm_wiki #obsidian #index

이 Vault는 공식 문서, 강의 자료, 검증된 레퍼런스를 공부하기 좋게 재구성한 LLM Wiki다. 목표는 개인 생각을 기본 근거로 삼는 second brain이 아니라, LLM이 검색해도 되는 공식/준공식 지식층을 만들고 프로젝트 경험은 적용 사례로만 연결하는 것이다.

## 지식 레이어

- 공식 지식 레이어: Permanent Note, Reference Note, Literature Note를 중심으로 정의, 공식/강의 근거, 사용 조건, 금지 조건을 정리한다.
- 프로젝트 적용 레이어: 실제 프로젝트에서 어떤 지식을 어떻게 썼는지 기록하되, 공식 개념 설명의 1차 근거로 쓰지 않는다.
- 개인 사고 레이어: 회고, 개발자 정체성, 개인 Dev Rules처럼 주관이 들어간 내용은 [[생각과 회고 MOC]]에서 관리한다.

## 운영 루프

- 새 강의 내용은 Literature Note에 먼저 남기고, 공식 문서나 검증된 레퍼런스로 보강한다.
- 개념은 Permanent Note로 쪼개되, 개인 판단이 아니라 정의와 조건 중심으로 쓴다.
- MOC에는 학습 경로와 문제 해결 경로를 유지한다.
- 실제 프로젝트에서 쓴 내용은 프로젝트 로그로 되돌리되, 공식 지식과 적용 사례를 한 문장 안에서 섞지 않는다.
- 개인 회고와 정체성 문장은 Thinking 레이어에 둔다.
