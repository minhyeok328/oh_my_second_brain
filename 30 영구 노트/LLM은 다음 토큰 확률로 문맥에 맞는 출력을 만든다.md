# LLM은 다음 토큰 확률로 문맥에 맞는 출력을 만든다

자동회귀 LLM은 지금까지의 토큰을 조건으로 다음 토큰의 확률 분포를 만들고, 그 과정을 반복해 출력을 이어 간다. GPT-3 연구가 큰 자동회귀 언어 모델의 문맥 내 학습을 보여 주었듯, 문맥과 지시는 출력 분포를 바꾸지만 모델을 사실 데이터베이스로 바꾸지는 않는다.

그래서 [[프롬프트는 모델에 전달하는 작업 계약이다]]가 역할·근거·출력 형식을 문맥에 명시하고, 최신 사실이 필요하면 [[RAG의 성능은 검색 단계의 품질에서 시작된다]]가 외부 근거를 공급해야 한다. 코드가 후속 처리를 해야 한다면 자유문장 대신 [[함수 호출은 자연어 요청을 구조화된 도구 입력으로 바꾼다]]로 경계를 좁힌다.

이 설명에는 범위가 있다. "다음 토큰 예측"은 자동회귀 LLM의 생성 원리를 요약하지만, 모든 모델 계열의 학습 목표나 내부 계산을 전부 설명하지는 않는다. 또한 확률이 높은 출력은 문맥에 자연스럽다는 뜻이지 사실이라는 뜻이 아니므로 계산, 권한 변경, 결제 같은 작업은 외부 검증 없이 실행하면 안 된다.
