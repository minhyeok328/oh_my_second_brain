# Python 파일 입출력

태그: #python #data #llm_wiki

## 한 줄 정의

파일 시스템의 텍스트, 바이너리, CSV 데이터를 읽고 쓰는 작업이다.

## 왜 중요한가

분석과 서비스는 외부 파일을 계속 만난다. 경로, 인코딩, 리소스 해제를 이해해야 데이터 손상과 파일 누수를 줄인다.

## 핵심 개념

- `with open(...)`은 파일을 안전하게 닫는다.
- 텍스트 인코딩을 명시하면 환경 차이를 줄인다.
- `os`와 `pathlib`로 경로를 다룬다.

## 예제

```python
from pathlib import Path
text = Path("memo.txt").read_text(encoding="utf-8")
```

## 실무 활용

CSV 로딩, 이미지 복사, 로그 저장, Obsidian 노트 생성 같은 자동화에 직접 쓰인다.
