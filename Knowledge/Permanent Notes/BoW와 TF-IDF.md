# BoW와 TF-IDF

태그: #nlp #vectorization #llm_wiki

## 한 줄 정의

문서를 단어 등장 횟수나 중요도 가중치 벡터로 표현하는 전통적 텍스트 벡터화 방식이다.

## 왜 중요한가

딥러닝 이전에도 강한 베이스라인을 만들 수 있고, 검색과 분류의 기본 원리를 이해하게 해준다.

## 핵심 개념

- BoW는 단어 빈도를 사용한다.
- TF-IDF는 흔한 단어의 가중치를 낮춘다.
- 희소 벡터가 만들어진다.

## 예제

```python
vectorizer = TfidfVectorizer()
X = vectorizer.fit_transform(texts)
```

## 실무 활용

문서 분류, 키워드 기반 검색, SVM 텍스트 분류 베이스라인에 사용한다.

## 언제 쓰면 안 되는가
