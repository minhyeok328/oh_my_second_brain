# PCA

태그: #machinelearning #dimensionality_reduction #llm_wiki

## 한 줄 정의

데이터 분산을 가장 잘 보존하는 축으로 차원을 줄이는 선형 기법이다.

## 왜 중요한가

고차원 데이터를 압축해 시각화하거나 노이즈를 줄이고 학습 속도를 높이는 데 사용한다.

## 핵심 개념

- 주성분은 서로 직교한다.
- 설명분산비로 보존된 정보량을 확인한다.
- 스케일링 후 적용하는 경우가 많다.

## 예제

```python
pca = PCA(n_components=2).fit_transform(X_scaled)
```

## 실무 활용

시각화, 피처 압축, 모델 입력 차원 축소에 활용한다.

## 내 말로 다시 설명

PCA은/는 강의에서 나온 개념을 정의, 사용 조건, 주의점, 연결 개념으로 다시 설명하기 위한 LLM wiki 원자 노트다. 단순 암기보다 실제 문제에서 언제 꺼내 쓸지 판단하는 데 초점을 둔다.

## 언제 쓰는가

- 강의 실습 코드에서 같은 개념을 다시 만날 때
- 프로젝트에서 관련 오류나 설계 결정을 설명해야 할 때
- [[Feature Scaling]], [[클러스터링]], [[EDA]]와 함께 문제 원인을 좁힐 때

## 언제 쓰면 안 되는가

- 구체적인 API 버전, 파라미터, 보안 정책이 필요한 경우에는 공식 문서를 먼저 확인한다.
- 예제 하나만 보고 모든 상황에 일반화해야 할 때는 보류한다.
- 이미 더 좁고 구체적인 노트가 있는 경우에는 그 노트로 이동한다.

## 자주 헷갈리는 점

- 이름이 비슷한 인접 개념과 책임 범위가 다를 수 있다.
- 강의 예제의 상황과 실제 프로젝트의 데이터, 환경, 버전 차이를 분리해야 한다.
- "동작한다"와 "운영에서 유지보수 가능하다"는 다른 기준이다.
