# Python 함수

태그: #python #programming #llm_wiki

## 한 줄 정의

입력을 받아 재사용 가능한 작업 단위로 묶은 코드 블록이다.

## 왜 중요한가

중복을 줄이고 테스트 가능한 단위로 로직을 분리한다. 지식 작업에서는 추출, 변환, 저장 단계를 함수로 나누면 파이프라인이 선명해진다.

## 핵심 개념

- `def`로 정의한다.
- 인자, 기본값, 반환값을 설계한다.
- 함수는 일급 객체라 변수에 담거나 다른 함수에 전달할 수 있다.

## 예제

```python
def normalize(text: str) -> str:
    return text.strip().lower()
```

## 실무 활용

전처리 함수, API 호출 래퍼, 모델 평가 함수처럼 반복되는 절차를 캡슐화한다.

## 내 말로 다시 설명

Python 함수은/는 강의에서 나온 개념을 정의, 사용 조건, 주의점, 연결 개념으로 다시 설명하기 위한 LLM wiki 원자 노트다. 단순 암기보다 실제 문제에서 언제 꺼내 쓸지 판단하는 데 초점을 둔다.

## 언제 쓰는가

- 강의 실습 코드에서 같은 개념을 다시 만날 때
- 프로젝트에서 관련 오류나 설계 결정을 설명해야 할 때
- [[Python 타입 힌트]], [[Python 람다 함수]], [[Python 모듈과 네임스페이스]]와 함께 문제 원인을 좁힐 때

## 언제 쓰면 안 되는가

- 구체적인 API 버전, 파라미터, 보안 정책이 필요한 경우에는 공식 문서를 먼저 확인한다.
- 예제 하나만 보고 모든 상황에 일반화해야 할 때는 보류한다.
- 이미 더 좁고 구체적인 노트가 있는 경우에는 그 노트로 이동한다.

## 자주 헷갈리는 점

- 이름이 비슷한 인접 개념과 책임 범위가 다를 수 있다.
- 강의 예제의 상황과 실제 프로젝트의 데이터, 환경, 버전 차이를 분리해야 한다.
- "동작한다"와 "운영에서 유지보수 가능하다"는 다른 기준이다.
