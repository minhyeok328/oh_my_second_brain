# 과적합

태그: #machinelearning #modeling #llm_wiki

## 한 줄 정의

모델이 훈련 데이터의 잡음까지 외워 새로운 데이터 성능이 떨어지는 현상이다.

## 왜 중요한가

실무 모델의 목표는 훈련 점수가 아니라 미래 데이터의 성능이다. 과적합을 제어하지 않으면 배포 후 성능이 무너진다.

## 핵심 개념

- 훈련 성능과 검증 성능 차이가 크면 의심한다.
- 모델 복잡도, 데이터 크기, 누수가 원인이 될 수 있다.
- 규제, 조기 종료, 교차검증, 데이터 증강으로 완화한다.

## 내 말로 다시 설명

과적합은/는 강의에서 나온 개념을 정의, 사용 조건, 주의점, 연결 개념으로 다시 설명하기 위한 LLM wiki 원자 노트다. 단순 암기보다 실제 문제에서 언제 꺼내 쓸지 판단하는 데 초점을 둔다.

## 언제 쓰는가

- 강의 실습 코드에서 같은 개념을 다시 만날 때
- 프로젝트에서 관련 오류나 설계 결정을 설명해야 할 때
- [[교차검증]], [[정규화와 드롭아웃]], [[하이퍼파라미터 튜닝]]와 함께 문제 원인을 좁힐 때

## 언제 쓰면 안 되는가

- 구체적인 API 버전, 파라미터, 보안 정책이 필요한 경우에는 공식 문서를 먼저 확인한다.
- 예제 하나만 보고 모든 상황에 일반화해야 할 때는 보류한다.
- 이미 더 좁고 구체적인 노트가 있는 경우에는 그 노트로 이동한다.

## 자주 헷갈리는 점

- 이름이 비슷한 인접 개념과 책임 범위가 다를 수 있다.
- 강의 예제의 상황과 실제 프로젝트의 데이터, 환경, 버전 차이를 분리해야 한다.
- "동작한다"와 "운영에서 유지보수 가능하다"는 다른 기준이다.
