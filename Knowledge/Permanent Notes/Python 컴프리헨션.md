# Python 컴프리헨션

태그: #python #programming #llm_wiki

## 한 줄 정의

반복과 조건을 이용해 새 컬렉션을 간결하게 만드는 표현식이다.

## 왜 중요한가

단순 변환과 필터링을 짧게 표현해 데이터 처리 코드를 읽기 쉽게 만든다.

## 핵심 개념

- 리스트, 딕셔너리, 세트 컴프리헨션이 있다.
- 조건 필터를 뒤에 붙일 수 있다.
- 중첩이 깊어지면 일반 반복문이 더 읽기 좋다.

## 예제

```python
names = [u["name"] for u in users if u.get("active")]
```

## 실무 활용

문서 청크 필터링, 컬럼명 정리, 파일 확장자별 목록 생성에 유용하다.

## 언제 쓰는가

- 강의 실습 코드에서 같은 개념을 다시 만날 때
- 프로젝트에서 관련 오류나 설계 결정을 설명해야 할 때
- [[Python 반복문]], [[Python 리스트]], [[Pandas 인덱싱]]와 함께 문제 원인을 좁힐 때

## 언제 쓰면 안 되는가

- 구체적인 API 버전, 파라미터, 보안 정책이 필요한 경우에는 공식 문서를 먼저 확인한다.
- 예제 하나만 보고 모든 상황에 일반화해야 할 때는 보류한다.
- 이미 더 좁고 구체적인 노트가 있는 경우에는 그 노트로 이동한다.

## 자주 헷갈리는 점

- 이름이 비슷한 인접 개념과 책임 범위가 다를 수 있다.
- 강의 예제의 상황과 실제 프로젝트의 데이터, 환경, 버전 차이를 분리해야 한다.
- "동작한다"와 "운영에서 유지보수 가능하다"는 다른 기준이다.
