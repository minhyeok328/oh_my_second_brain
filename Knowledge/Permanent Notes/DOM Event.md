# DOM Event

태그: #javascript #web #llm_wiki

## 한 줄 정의

사용자 클릭, 입력, 제출 같은 브라우저 상호작용을 처리하는 메커니즘이다.

## 왜 중요한가

웹 앱은 이벤트에 반응해 상태와 화면을 바꾸는 구조다.

## 핵심 개념

- `addEventListener`로 이벤트 핸들러를 등록한다.
- 이벤트 객체에는 대상과 추가 정보가 있다.
- 기본 동작 방지와 이벤트 전파 제어가 필요할 수 있다.

## 예제

```js
button.addEventListener("click", () => alert("clicked"));
```

## 실무 활용

폼 제출 검증, 버튼 액션, 동적 리스트 조작에 사용한다.

## 내 말로 다시 설명

DOM Event은/는 강의에서 나온 개념을 정의, 사용 조건, 주의점, 연결 개념으로 다시 설명하기 위한 LLM wiki 원자 노트다. 단순 암기보다 실제 문제에서 언제 꺼내 쓸지 판단하는 데 초점을 둔다.

## 언제 쓰는가

- 강의 실습 코드에서 같은 개념을 다시 만날 때
- 프로젝트에서 관련 오류나 설계 결정을 설명해야 할 때
- [[DOM]], [[JavaScript 함수와 스코프]], [[JavaScript 비동기]]와 함께 문제 원인을 좁힐 때

## 언제 쓰면 안 되는가

- 구체적인 API 버전, 파라미터, 보안 정책이 필요한 경우에는 공식 문서를 먼저 확인한다.
- 예제 하나만 보고 모든 상황에 일반화해야 할 때는 보류한다.
- 이미 더 좁고 구체적인 노트가 있는 경우에는 그 노트로 이동한다.

## 자주 헷갈리는 점

- 이름이 비슷한 인접 개념과 책임 범위가 다를 수 있다.
- 강의 예제의 상황과 실제 프로젝트의 데이터, 환경, 버전 차이를 분리해야 한다.
- "동작한다"와 "운영에서 유지보수 가능하다"는 다른 기준이다.
