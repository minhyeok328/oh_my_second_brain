# 교차검증

태그: #machinelearning #sklearn #llm_wiki

## 한 줄 정의

데이터를 여러 fold로 나누어 학습과 검증을 반복하는 평가 방법이다.

## 왜 중요한가

한 번의 train/test split은 운에 민감하다. 교차검증은 더 안정적인 일반화 성능 추정치를 제공한다.

## 핵심 개념

- KFold는 데이터를 K개로 나눈다.
- StratifiedKFold는 클래스 비율을 보존한다.
- 튜닝과 성능 보고에서 검증 데이터 누수를 조심한다.

## 예제

```python
scores = cross_val_score(model, X, y, cv=5)
```

## 실무 활용

모델 선택, 하이퍼파라미터 튜닝, 작은 데이터셋 평가에 사용한다.
