# NumPy 브로드캐스팅

태그: #numpy #data_analysis #llm_wiki

## 한 줄 정의

서로 다른 shape의 배열을 규칙에 따라 맞춰 벡터화 연산하는 기능이다.

## 왜 중요한가

반복문 없이 스케일링, 정규화, 거리 계산을 구현할 수 있어 수치 계산 코드를 단순하게 만든다.

## 핵심 개념

- 뒤쪽 차원부터 크기가 같거나 1이면 연산 가능하다.
- 실제 복사 없이 논리적으로 확장해 계산한다.
- shape 오류는 대부분 브로드캐스팅 규칙 불일치에서 온다.

## 예제

```python
x = np.array([[1, 2], [3, 4]])
x - x.mean(axis=0)
```

## 실무 활용

표준화, 이미지 채널 처리, 배치 단위 손실 계산에 쓰인다.
