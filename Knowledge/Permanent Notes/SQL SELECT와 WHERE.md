# SQL SELECT와 WHERE

태그: #sql #database #llm_wiki

## 한 줄 정의

테이블에서 필요한 열과 행을 조회하고 조건으로 필터링하는 SQL의 중심 구문이다.

## 왜 중요한가

분석과 서비스 조회의 대부분은 원하는 데이터를 정확히 가져오는 문제다. 조건을 잘못 쓰면 모델 학습 데이터도 왜곡된다.

## 핵심 개념

- `SELECT`는 열을 고른다.
- `WHERE`는 행을 제한한다.
- `ORDER BY`, `LIMIT`으로 결과 순서와 크기를 조정한다.

## 예제

```sql
SELECT name, price
FROM menu
WHERE price >= 10000
ORDER BY price DESC;
```

## 실무 활용

리포트 조회, 추천 후보 생성, 백엔드 목록 API의 데이터 검색에 사용한다.

## 언제 쓰면 안 되는가

- 구체적인 API 버전, 파라미터, 보안 정책이 필요한 경우에는 공식 문서를 먼저 확인한다.
- 예제 하나만 보고 모든 상황에 일반화해야 할 때는 보류한다.
- 이미 더 좁고 구체적인 노트가 있는 경우에는 그 노트로 이동한다.
