# JavaScript 프로토타입

태그: #javascript #web #llm_wiki

## 한 줄 정의

객체가 다른 객체를 상속해 속성과 메서드를 찾아가는 JavaScript의 상속 메커니즘이다.

## 왜 중요한가

클래스 문법 뒤에도 프로토타입 체인이 동작한다. 객체 모델을 이해하면 메서드 공유와 상속 버그를 파악할 수 있다.

## 핵심 개념

- 객체는 prototype 링크를 통해 속성을 찾는다.
- 생성자 함수는 prototype 객체를 가진다.
- class 문법은 프로토타입 기반 상속의 문법적 설탕이다.

## 예제

```js
function User(name) { this.name = name; }
User.prototype.sayHi = function () { return this.name; };
```

## 실무 활용

라이브러리 객체 확장, 클래스 기반 컴포넌트 이해, JS 런타임 디버깅에 도움 된다.
