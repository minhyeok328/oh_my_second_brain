## 실제 사용 지식 인덱스

### 1차 차량 TCO

- 문제: 차량 유지비를 구매 가격과 분리해 월 단위 TCO로 비교해야 했다.
- 적용한 개념: [[Streamlit 기본 UI]], [[Streamlit Session State]], [[MySQL Connector Python]], [[Pandas DataFrame]], [[SQL SELECT와 WHERE]]
- 결과: 차량 모델 검색, 연비/유가/정비 주기 조회, 월 유지비 계산 흐름을 Streamlit UI로 묶었다.
- 다음 보강: DB query 안전성, 외부 API 실패 처리, 계산 단위 통일 기준

### 2차 카드 이탈 예측

- 문제: 카드 이탈을 단일 지표가 아니라 행동 패턴과 고객 맥락으로 설명해야 했다.
- 적용한 개념: [[EDA]], [[Feature Engineering]], [[XGBoost]], [[MLflow]], [[FastAPI]], [[Docker Compose]], [[Streamlit 기본 UI]]
- 결과: 모델별 성능 비교, MLflow 최신 모델 로드, Streamlit 전략 대시보드, pipeline API를 구성했다.
- 다음 보강: Unknown income 보정 전략, 과적합 검증, 모델 artifact 관리

### 3차 PICKLE RAG 챗봇

- 문제: 맛집 추천에서 hallucination을 줄이고 DB에 존재하는 식당만 근거로 답해야 했다.
- 적용한 개념: [[RAG]], [[LangGraph]], [[Function Calling]], [[Embedding]], [[Retriever]], [[SQLite]], [[RAG 평가]]
- 결과: fixed/embedding route, slot extraction, DB 검색, 후보 기반 답변 생성, goldset 평가 체계를 만들었다.
- 다음 보강: [[RAG 평가 질문 세트]], [[RAG 검색 실패 사례]], route/payload/target/answer/retrieval별 실패 분석

### 4차 LG Home

- 문제: LG 가전 검색, 사용설명서 Q&A, 찜 기반 개인화, 후속 질문을 한 서비스에서 처리해야 했다.
- 적용한 개념: [[Django Chatbot]], [[Django ORM Model]], [[Django Template]], [[LangGraph]], [[Vector Store]], [[RAG]], [[Django CSRF]]
- 결과: Django SSR 기반 가전 서비스, LangGraph 상담 챗봇, Pinecone 매뉴얼 RAG, AJAX JSON API를 구성했다.
- 다음 보강: 후속 질문 state 관리, 제품군별 검색 조건 병합, API 실패 UX 공통화

### 4차 이후 개인 확장

- 문제: 공식 4차 프로젝트 이후 Django SSR 구조를 React SPA + Django JSON API로 분리해 보고 싶었다.
- 적용한 개념: [[React SPA]], [[React API Fetch]], [[Django JSON API]], [[Django CSRF]]
- 결과: `4th_project_change_react`에서 프론트 렌더링과 Django API 책임을 분리하는 확장 실험을 진행했다.
- 다음 보강: 공식 프로젝트와 개인 실험의 출처 구분 유지
