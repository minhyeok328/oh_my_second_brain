# Conda 환경 설정

태그: #python #reference #llm_wiki

## 용도

강의 실습 환경을 재현하기 위한 Conda 명령 모음이다.

## 빠른 참조

- `conda env create -f environment.yml`: 환경 파일로 생성
- `conda activate <env>`: 환경 활성화
- `conda env export > environment.yml`: 현재 환경 내보내기
- `conda remove -n <env> --all`: 환경 삭제
