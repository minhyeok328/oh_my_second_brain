# OpenAI API 기본 호출

태그: #llm #reference #llm_wiki

## 용도

LLM API 호출 시 확인할 기본 요소다.

## 빠른 참조

- `OPENAI_API_KEY`: 환경변수로 API 키 관리
- `model`: 사용 모델 지정
- `input/messages`: 사용자 입력과 시스템 지시
- `temperature`: 생성 다양성 조절
- `stream`: 응답 스트리밍
