# Django 명령어 모음

태그: #django #reference #llm_wiki

## 용도

Django 프로젝트 개발에서 반복 사용하는 명령이다.

## 빠른 참조

- `django-admin startproject config`: 프로젝트 생성
- `python manage.py startapp app`: 앱 생성
- `python manage.py makemigrations`: 마이그레이션 파일 생성
- `python manage.py migrate`: DB 반영
- `python manage.py runserver`: 개발 서버 실행
