# React Hooks 치트시트

태그: #react #reference #llm_wiki

## 용도

React Hook의 쓰임을 빠르게 구분한다.

## 빠른 참조

- `useState`: 지역 UI 상태
- `useEffect`: 외부 시스템 동기화
- `useReducer`: 복잡한 상태 전이
- `useMemo`: 계산 결과 메모이제이션
- `useCallback`: 함수 참조 메모이제이션
- `useRef`: 렌더링 없는 mutable 참조
- `useContext`: Context 값 읽기
