# Docker Compose

태그: #docker #reference #llm_wiki

## 용도

여러 컨테이너를 함께 실행하는 Compose 명령이다.

## 빠른 참조

- `docker compose up`: 서비스 실행
- `docker compose up -d`: 백그라운드 실행
- `docker compose down`: 서비스 종료
- `docker compose logs -f`: 로그 팔로우
- `docker compose build`: 이미지 재빌드
