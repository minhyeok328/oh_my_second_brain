# React Router 치트시트

태그: #react #reference #llm_wiki

## 용도

React SPA 라우팅 구성요소를 정리한다.

## 빠른 참조

- `<BrowserRouter>`: 라우터 컨텍스트 제공
- `<Routes>`: Route 목록 컨테이너
- `<Route path element>`: 경로와 컴포넌트 매핑
- `useParams()`: URL 파라미터 읽기
- `useNavigate()`: 프로그래밍 방식 이동
