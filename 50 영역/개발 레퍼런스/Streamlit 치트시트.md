# Streamlit 치트시트

태그: #streamlit #reference #llm_wiki

## 용도

Streamlit 화면 구성 기본 명령을 모은다.

## 빠른 참조

- `st.title(text)`: 제목 출력
- `st.write(obj)`: 일반 출력
- `st.dataframe(df)`: 표 출력
- `st.text_input(label)`: 텍스트 입력
- `st.session_state`: 세션 상태 저장
