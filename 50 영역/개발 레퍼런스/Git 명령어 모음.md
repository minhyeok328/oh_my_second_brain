# Git 명령어 모음

태그: #git #reference #llm_wiki

## 용도

버전 관리 작업에서 자주 쓰는 Git 명령이다.

## 빠른 참조

- `git status`: 변경 상태 확인
- `git add <file>`: 스테이징
- `git commit -m "message"`: 커밋 생성
- `git log --oneline`: 이력 확인
- `git branch`: 브랜치 목록
