# Docker CLI

태그: #docker #reference #llm_wiki

## 용도

이미지와 컨테이너 작업에서 자주 쓰는 Docker 명령이다.

## 빠른 참조

- `docker build -t name .`: 이미지 빌드
- `docker images`: 이미지 목록
- `docker run -p 8000:8000 name`: 컨테이너 실행
- `docker ps`: 실행 컨테이너 확인
- `docker logs <container>`: 로그 확인
