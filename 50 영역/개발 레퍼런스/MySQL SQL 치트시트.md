# MySQL SQL 치트시트

태그: #sql #mysql #reference #llm_wiki

## 용도

MySQL 조회와 변경 기본 명령을 모은다.

## 빠른 참조

- `SHOW DATABASES;`: 데이터베이스 목록
- `USE db;`: 데이터베이스 선택
- `SELECT * FROM table WHERE condition;`: 조건 조회
- `INSERT INTO table (...) VALUES (...);`: 행 삽입
- `COMMIT;`: 트랜잭션 확정
