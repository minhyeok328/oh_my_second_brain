# JavaScript DOM 치트시트

태그: #javascript #reference #llm_wiki

## 용도

브라우저 DOM 조작과 이벤트 처리 기본 명령이다.

## 빠른 참조

- `document.querySelector(selector)`: 요소 선택
- `el.textContent = value`: 텍스트 변경
- `el.classList.add(name)`: 클래스 추가
- `el.addEventListener('click', fn)`: 이벤트 등록
- `fetch(url)`: HTTP 요청
