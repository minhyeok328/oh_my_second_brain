# 시각화 치트시트

## 용도

데이터의 추세, 분포, 범주별 차이와 행렬을 빠르게 살필 때 기본 그래프를 고른다.

## 빠른 참조

- `plt.plot(x, y)`: 순서나 연속 축에 따른 선 그래프
- `plt.hist(x, bins=...)`: 한 변수의 구간별 분포
- `sns.boxplot(data=df, x=..., y=...)`: 범주별 분포 요약과 이상치 후보 확인
- `sns.heatmap(matrix, annot=...)`: 행렬 값을 색으로 표현
- `plt.xlabel(...)`, `plt.ylabel(...)`, `plt.title(...)`: 축 의미와 제목 명시

## 사용 전 확인

- 그래프가 답하려는 질문과 x/y 단위, 집계 기준, 결측치 처리 방식을 함께 기록한다.
- 상관관계 heatmap은 인과관계를 증명하지 않는다.
- 표본 수와 분포가 가려지면 점 그래프나 원자료 요약을 함께 본다.

## 검증 범위

- 2026-08-11: Matplotlib `pyplot`과 seaborn 공식 API 레퍼런스에서 위 함수의 용도를 확인했다.
- 설치 버전, theme, figure lifecycle, 대용량 데이터 성능과 접근성 색상은 검증하지 않았다.
