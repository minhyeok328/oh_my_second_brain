# 기술 학습

## 기초에서 데이터로

- [[Python 학습 지도]]에서 실행·상태 경계를 익힌 뒤 [[MySQL 학습 지도]]로 영속성 경계를 연결한다.
- [[데이터 수집 학습 지도]]에서 입력의 실패 조건을 정하고 [[데이터 분석 학습 지도]]에서 표 구조와 탐색 질문으로 바꾼다.

## 모델링으로

- [[머신러닝 학습 지도]]에서 데이터 분리와 평가를 먼저 고정한다.
- [[딥러닝 기초 학습 지도]]에서 학습 계산을 확인하고 [[NLP 딥러닝 학습 지도]]와 [[멀티모달 딥러닝 학습 지도]]에서 입력 표현에 따른 경로를 나눈다.
- [[LLM과 RAG 학습 지도]]에서 생성 모델, 검색과 평가 경계를 프로젝트 질문으로 확장한다.

## 서비스와 운영으로

- [[웹 클라이언트 학습 지도]]와 [[웹 서버 학습 지도]]에서 화면·요청·데이터 책임을 연결한다.
- [[DevOps 학습 지도]]에서 실행 환경과 배포 경계를 점검한다.

## 현재 학습 질문

- [[질문 인박스]]: QuerySet, React 요청 순서와 Compose readiness 등 여러 지도의 미답변 항목을 모은다.
- [[RAG 평가 질문 세트]] → [[RAG 검색 실패 사례]]: 평가 조건을 고정한 뒤 실제 실패 위치를 기록하는 순서로 사용한다.

이 영역은 학습 순서를 정하는 내비게이션이며, 링크된 노트의 사실 검증을 대신하지 않는다.
