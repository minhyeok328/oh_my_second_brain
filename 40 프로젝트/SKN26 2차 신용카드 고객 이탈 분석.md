# SKN26 2차 신용카드 고객 이탈 분석

## 프로젝트 사실

- BankChurners 데이터를 탐색하고 여러 분류 모델을 비교해 고객 이탈 신호와 세그먼트별 유지 전략을 검토한 팀 프로젝트다. 실제 금융 데이터가 아닌 비식별 오픈 데이터이므로 결과를 실무 임계치로 바로 적용할 수 없다고 README가 제한한다. (근거: `README.md` 1장, 6장, 12장)
- 저장소에는 MySQL 데이터 적재 파이프라인, FastAPI, MLflow, Streamlit과 Docker Compose 구성이 함께 있다. 이는 팀 산출물의 범위를 보여줄 뿐 개인 담당을 증명하지 않는다. (근거: `README.md` 실행 방법·프로젝트 구조, `docker-compose.yaml`)
- 기간 출처가 충돌한다. README는 `2026-03-04 ~ 2026-03-16`, 개인 포트폴리오는 `2026-03-16 ~ 2026-03-17`로 적는다. 어느 쪽도 임의로 정정하지 않고 불일치로 남긴다. (근거: `README.md` 개발 기간, 포트폴리오 상세 모달, 2026-08-11 확인)

## 팀 산출물

- 팀 여섯 명은 모델링과 Data Pipeline·Streamlit·Docs·Presentation 역할을 나눴고, 두 명에게 배정된 XGBoost를 포함해 XGBoost·HistGradientBoosting·EasyEnsemble·Logistic Regression·LightGBM의 다섯 종류 분류 알고리즘·모델을 비교했다. 거래 횟수·거래 금액·비활성 기간·고객센터 접촉 같은 행동 변수도 이탈 신호로 분석했다. (근거: `README.md` 팀 소개, 6장, 7장)
- 예측 모델과 데이터 파이프라인, 실험 추적, 대시보드를 하나의 실행 구성으로 묶었다. 개별 모듈의 저장소 존재를 특정인의 소유로 해석하지 않는다. (근거: `README.md` 2장, 11장, `docker-compose.yaml`)

## 직접 기여

- README 팀 표는 서민혁에게 XGBoost 기반 Income Modeling과 Data Pipeline 역할을 배정한다. 개인 회고도 데이터 파이프라인과 Unknown 소득 구간 예측 실험을 직접 수행했다고 적는다. (근거: `README.md` 팀 소개, 개인 회고)
- 저장소의 `notebooks\SeoMinHyeok`에는 소득 분석, Unknown 예측과 XGBoost 실험 노트북이 있다. 폴더명과 README 귀속이 일치하지만, 성능 향상이나 운영 반영은 별도 근거 없이 확대하지 않는다. (근거: `notebooks\SeoMinHyeok`, `README.md` 개인 회고)
- 포트폴리오는 EDA·전처리 탐색과 Streamlit 초기 화면도 직접 기여로 적는다. README 역할 표에는 Streamlit 담당이 다른 팀원에게 배정되어 있으므로, Streamlit 항목은 개인 포트폴리오의 서술이며 최종 화면 전체의 소유권을 뜻하지 않는다. (근거: 포트폴리오 상세 모달, `README.md` 팀 역할 표)

## 의사결정과 근거

- 소득의 `Unknown` 값을 바로 삭제하지 않고 알려진 구간으로 예측할 수 있는지 먼저 실험했다. 데이터 손실을 줄이려는 선택이었지만 실제 Unknown 보완과 운영 파이프라인 반영까지 완료되지는 않았다. (근거: `README.md` 개인 회고·한계점, 포트폴리오 프로젝트 개요)
- 다중 소득 구간의 분류 결과가 기대보다 낮아 특성 분포를 다시 보고 Low/High 이진 구간도 별도로 실험했다. 이 결정은 [[특성 공학은 모델보다 먼저 데이터 표현을 개선한다]]와 연결된다. (근거: 포트폴리오 기술 설계와 판단, `model_evaluation.md`)

## 실패·디버깅

- 다중 소득 구간 분류는 기대한 성능에 도달하지 못했고, Unknown 값을 채워 운영 데이터에 반영하는 작업도 완료되지 않았다. 결과를 성공한 결측치 보정으로 표현하지 않는다. (근거: 포트폴리오 프로젝트 개요·기술 설계와 판단, `README.md` 한계점)
- 기간 표기가 README와 포트폴리오에서 다르다. 이 문서 증거 불일치는 해소 전까지 유지한다. (근거: `README.md` 개발 기간, 포트폴리오 상세 모달)

## 회고
