# MySQL 학습 지도

## 출발점

- [[20 소스 노트/강의/MySQL과 관계형 데이터베이스 강의|MySQL과 관계형 데이터베이스 강의]]: 테이블 관계를 기준으로 조회, 변경과 트랜잭션을 순서대로 복습한다.

## 핵심 연결

1. [[SELECT와 WHERE는 조회 범위와 조건을 분리한다]] — 필요한 열과 행 조건을 분리해 조회의 기본 경계를 잡는다.
2. [[50 영역/개발 레퍼런스/MySQL SQL 치트시트|MySQL SQL 치트시트]] — 조인, 집계와 트랜잭션 문법을 실습할 때 빠르게 확인한다.
3. [[MySQL Connector는 SQL 실행과 트랜잭션 경계를 명시해야 한다]] — SQL을 애플리케이션 코드에서 실행할 때 커넥션과 커밋 책임을 연결한다.

## 프로젝트에서의 적용

- [[SKN26 2차 신용카드 고객 이탈 분석]]: MySQL 적재 파이프라인이 팀 실행 구성에 포함됐다.
