# LLM과 RAG 학습 지도

## 출발점

- [[20 소스 노트/강의/LLM과 RAG 강의|LLM과 RAG 강의]]: 모델 호출에서 인덱싱·검색·생성·평가와 상태 그래프까지 경계를 나누어 본다.

## 핵심 연결

1. [[LLM은 다음 토큰 확률로 문맥에 맞는 출력을 만든다]] → [[프롬프트는 모델에 전달하는 작업 계약이다]] — 모델 출력의 성격을 알고 입력 계약을 설계한다.
2. [[임베딩은 의미 기반 비교를 위한 좌표 표현이다]] → [[벡터 저장소는 임베딩과 메타데이터를 함께 관리해야 한다]] → [[검색기는 질문과 관련된 근거 후보를 좁힌다]] — 인덱싱과 검색의 데이터 계약을 순서대로 연결한다.
3. [[RAG의 성능은 검색 단계의 품질에서 시작된다]] → [[RAG 평가는 검색과 생성을 분리해서 측정해야 한다]] — 생성 답변만 보지 않고 실패 위치를 측정한다.
4. [[LangGraph 상태는 노드 사이의 데이터 계약이다]] → [[조건부 엣지는 상태에 따라 다음 실행 경로를 선택한다]] — 여러 단계를 상태와 분기로 명시한다.
