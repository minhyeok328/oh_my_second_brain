# 데이터 분석 학습 지도

## 출발점

- [[20 소스 노트/강의/데이터 분석 강의|데이터 분석 강의]]: 배열, 표, 시각화와 EDA를 데이터 질문이 구체화되는 순서로 따라간다.

## 핵심 연결

1. [[DataFrame은 열 단위 데이터 변환을 구조화한다]] — 열의 의미와 변환 단계를 명시하는 분석 단위를 잡는다.
2. [[50 영역/개발 레퍼런스/Pandas 치트시트|Pandas 치트시트]] — 선택, 결측치, 집계와 결합 작업을 재현할 때 참고한다.
3. [[50 영역/개발 레퍼런스/시각화 치트시트|시각화 치트시트]] — 분포와 관계를 확인하되 그래프를 인과 설명으로 확대하지 않는다.
4. [[특성 공학은 모델보다 먼저 데이터 표현을 개선한다]] — EDA에서 얻은 관찰을 모델 입력 표현의 가설로 넘긴다.

## 프로젝트에서의 적용

- [[SKN26 2차 신용카드 고객 이탈 분석]]: EDA와 소득 구간 전처리·특성 표현을 모델 비교의 앞 단계로 사용했다.
