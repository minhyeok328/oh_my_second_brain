## 핵심 연결

1. [[50 영역/개발 레퍼런스/JavaScript DOM 치트시트|JavaScript DOM 치트시트]] — 브라우저 요소 조회와 이벤트 처리를 확인한다.
2. [[React SPA는 화면 상태와 서버 상태의 경계를 분명히 해야 한다]] → [[useEffect는 외부 시스템과 React 상태를 동기화한다]] — 별도 공식 근거로 승격된 React 상태 경계를 연결한다.
3. [[React API 요청은 로딩 실패 취소 상태를 함께 다뤄야 한다]] → [[오래된 비동기 응답은 최신 상태를 덮지 못하게 해야 한다]] — 요청 수명주기와 응답 순서 문제를 UI 상태로 다룬다.
4. [[인증 만료는 오류가 아니라 사용자 흐름의 일부다]] → [[프론트엔드 상태는 권한 경계와 함께 정리해야 한다]] — 인증과 권한 변화가 화면 상태에 미치는 영향을 분리한다.
