# 멀티모달 딥러닝 학습 지도

## 출발점

- [[20 소스 노트/강의/멀티모달 딥러닝 강의|멀티모달 딥러닝 강의]]: 이미지 분류, 이미지·텍스트 정렬, 생성과 멀티모달 검색을 서로 다른 평가 문제로 본다.

## 핵심 연결

1. [[50 영역/개발 레퍼런스/PyTorch 학습 루프 치트시트|PyTorch 학습 루프 치트시트]] — 이미지 모델 학습의 반복 구조와 평가 전환을 점검한다.
2. [[임베딩은 의미 기반 비교를 위한 좌표 표현이다]] — 이미지와 텍스트 표현을 비교하는 공통 좌표 관점을 잡는다.
3. [[검색기는 질문과 관련된 근거 후보를 좁힌다]] → [[벡터 저장소는 임베딩과 메타데이터를 함께 관리해야 한다]] — 검색 단위와 원본 메타데이터를 함께 추적한다.
4. [[RAG 평가는 검색과 생성을 분리해서 측정해야 한다]] — 캡션 오류, 검색 오류와 생성 오류를 한 점수로 섞지 않는다.

## 프로젝트에서의 적용

- 현재 승인된 프로젝트 허브에는 멀티모달 딥러닝을 직접 적용했다는 근거가 없다.
