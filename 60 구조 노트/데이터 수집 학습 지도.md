# 데이터 수집 학습 지도

## 출발점

- [[20 소스 노트/강의/데이터 수집 강의|데이터 수집 강의]]: API, 정적 HTML과 브라우저 자동화의 차이를 보고 공통 응답·저장 경계를 찾는다.

## 핵심 연결

1. [[HTTP 요청은 타임아웃과 실패 처리를 기본값으로 가져야 한다]] — 수집 성공뿐 아니라 지연과 실패 응답을 먼저 설계한다.
2. [[50 영역/개발 레퍼런스/Python 치트시트|Python 치트시트]] — 수집 스크립트의 실행 환경과 파일 처리를 확인한다.
3. [[MySQL Connector는 SQL 실행과 트랜잭션 경계를 명시해야 한다]] — 수집 결과를 저장할 때 요청 경계와 DB 경계를 분리한다.

## 프로젝트에서의 적용

- [[SKN26 1차 차량 운영비 프로젝트]]: 외부 연비 API 응답과 CSV를 정규화해 계산 흐름에 전달했다.
