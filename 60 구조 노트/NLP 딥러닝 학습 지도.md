# NLP 딥러닝 학습 지도

## 출발점

- [[20 소스 노트/강의/NLP 딥러닝 강의|NLP 딥러닝 강의]]: 전처리와 벡터화 선택이 순차 모델·Transformer의 입력과 평가를 어떻게 제한하는지 따라간다.

## 핵심 연결

1. [[50 영역/개발 레퍼런스/NLP 전처리 치트시트|NLP 전처리 치트시트]] — 정제, 토큰화와 패딩의 선택을 입력 계약으로 기록한다.
2. [[임베딩은 의미 기반 비교를 위한 좌표 표현이다]] — 텍스트 단위를 비교 가능한 벡터로 바꾸는 의미를 연결한다.
3. [[50 영역/개발 레퍼런스/PyTorch 학습 루프 치트시트|PyTorch 학습 루프 치트시트]] — 순차 모델과 전이 학습의 반복 학습 구조를 점검한다.
4. [[분류 평가는 클래스 불균형에 맞는 지표를 선택해야 한다]] — 텍스트 분류의 데이터 분포에 맞춰 평가 기준을 고른다.
