# 딥러닝 기초 학습 지도

## 출발점

- [[20 소스 노트/강의/딥러닝 기초 강의|딥러닝 기초 강의]]: 퍼셉트론에서 손실·역전파·최적화·정규화까지 계산 흐름을 따라간다.

## 핵심 연결

1. [[50 영역/개발 레퍼런스/PyTorch 학습 루프 치트시트|PyTorch 학습 루프 치트시트]] — 데이터, 순전파, 손실, 역전파와 갱신 순서를 실행 코드로 확인한다.
2. [[학습 데이터와 평가 데이터는 모델 선택 전에 분리해야 한다]] — 학습 손실과 일반화 성능을 같은 값처럼 다루지 않는다.
3. [[50 영역/개발 레퍼런스/Scikit-learn 워크플로우|Scikit-learn 워크플로우]] — 평가 분리와 재현성 원칙을 모델 종류와 무관하게 비교한다.
