# 머신러닝 학습 지도

## 출발점

- [[20 소스 노트/강의/머신러닝 강의|머신러닝 강의]]: 알고리즘 목록보다 데이터 분리, 전처리, 평가와 검증 절차를 먼저 익힌다.

## 핵심 연결

1. [[학습 데이터와 평가 데이터는 모델 선택 전에 분리해야 한다]] — 모델을 보기 전에 평가 경계를 고정한다.
2. [[특성 공학은 모델보다 먼저 데이터 표현을 개선한다]] — 입력 표현을 가설과 실험 대상으로 다룬다.
3. [[분류 평가는 클래스 불균형에 맞는 지표를 선택해야 한다]] — 정확도 하나로 불균형 문제를 판단하지 않는다.
4. [[XGBoost는 약한 트리를 순차적으로 보완한다]] — 부스팅 모델의 학습 구조를 구체 사례로 이해한다.
5. [[50 영역/개발 레퍼런스/Scikit-learn 워크플로우|Scikit-learn 워크플로우]] — 분리·전처리·학습·평가 순서를 코드로 점검한다.

## 프로젝트에서의 적용

- [[SKN26 2차 신용카드 고객 이탈 분석]]: XGBoost를 포함한 분류 모델 비교와 소득 구간 특성 실험, MLflow 추적을 수행했다.
